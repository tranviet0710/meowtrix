# MEOWTRIX
### 🐾 The Concept: Feline Overlord Tracker

Instead of a standard "lost pet" app, you are building a tongue-in-cheek tracking dashboard for "feline overlords." This playful, spy-agency framing directly targets the 15% **Theme Relevance** criteria while allowing you to build serious, complex architecture under the hood.

---

### 💻 The Winning Architecture & Tech Stack

To maximize the 25% **Technical Execution** and 20% **Innovation** categories, you need a highly reliable, zero-budget stack that deploys instantly and natively supports the sponsor tools.

* **Frontend & UI:** **Next.js** using **TypeScript**, styled with **Tailwind CSS** and **shadcn/ui**. This allows you to rapidly build a sleek, dark-mode dashboard without getting bogged down in custom CSS.
* **Database & Auth:** **Supabase (PostgreSQL)**. This provides instant user authentication and relational database storage for the tracking logs.
* **Mapping Engine:** **Leaflet.js** with OpenStreetMap. Open-source, entirely free, and easy to layer custom overlays onto.
* **AI Engine:** **Gemini API**. Highly generous free tier for processing images and extracting visual traits from uploaded cat photos.
* **Hosting:** **Vercel** for seamless, continuous deployment.

### 🏆 The Sponsor Integrations (Scoring Strategy)

This is how you will specifically cater to the judges and secure points across the board:

**2. The Aikido Flex (Security - 15%)**

* **The Play:** Connect Aikido's free "Developer" tier directly to your GitHub repository on Day 1. Use it to run Dependency Scanning and SAST (Static Application Security Testing). Build a multi-step verification process before a user can "claim" a found cat.
* **The Points:** Dedicate a section in your documentation to your clean Aikido security dashboard. Protecting user data (and feline coordinates) is an easy way to max out this category.

**3. The Temporal Flex (Technical Execution & Innovation - 45%)**

* **The Play:** Build the **"Escalating Search Protocol."** Write a Temporal background workflow that manages time-delayed actions. When an overlord goes missing, Temporal waits exactly 1 hour to notify nearby users. If not found in 6 hours, Temporal automatically generates a printable PDF missing poster.
* **The Points:** Temporal is built for durable, long-running processes. Using it to manage a multi-tiered, time-based escalation system shows advanced architectural thinking.

### 🧠 Stand-Out Core Features

* **Predictive Trajectory Mapping:** Don't just drop a pin. Use mapping logic to generate a "High Probability Zone" heatmap overlay on Leaflet.js based on how long the cat has been missing and average roaming distances.
* **Granular AI Vision Tags:** When a user uploads a "Spotted Agent" photo, use the Gemini API to extract specific tags (e.g., "Orange Tabby", "White Paws"). Save these to your PostgreSQL database to enable highly accurate matchmaking.
* **"Hooman Informant" Leaderboard:** Gamify the experience by rewarding users with points for uploading photos that lead to successful matches. A sleek UI here locks in the UX/UI score.
